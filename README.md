# AniTrack

AniTrack is a full-stack anime tracking web application that allows users to search for anime, manage watchlists, and track viewing progress. Users can organize anime into categories such as Watching, Completed, and Plan to Watch.

---

## Features

- Search for anime titles
- Create and manage personal watchlists
- Track anime progress
- Organize anime by status:
  - Watching
  - Completed
  - Plan to Watch
- Responsive user interface
- API-powered anime data
